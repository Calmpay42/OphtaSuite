# OphtaSuite

Logiciel de gestion de cabinet d'ophtalmologie : patients, consultations, examens, ordonnances, certificats.

Version actuelle : **1.9.3**

## Structure du dépôt

```
OphtaSuite/
├── README.md
├── .gitignore
└── docs/                        <- dossier publié par GitHub Pages
    ├── .nojekyll
    ├── index.html               <- page d'accueil (téléchargement + accès web)
    ├── app/
    │   └── index.html           <- application web complète
    └── download/
        └── OphtaSuite-1.9.3.apk <- application Android
```

## Utilisation

- **Android** : télécharger l'APK depuis la page d'accueil ou la section *Releases*, puis l'installer (autoriser les sources inconnues).
- **Web** : ouvrir `https://<VOTRE-PSEUDO>.github.io/<NOM-DU-DEPOT>/app/`

## Avertissement

Cette application manipule des données de santé. Les données restent sur l'appareil de l'utilisateur ; effectuez des sauvegardes régulières et respectez la réglementation locale sur les données médicales.
